# Claude Code에 전달할 요청

첨부한 pig-react-kit을 현재 React 가계부 앱에 통합해 주세요.

1. `public/pig-assets` PNG 6장을 프로젝트 정적 이미지 경로에 복사하고 `src/PigStatus.jsx`, `pig-status.css`, `pig-state.mjs`를 프로젝트 구조에 맞춰 추가하세요. 기존 규칙이 TypeScript이면 타입을 붙여 변환하되 디자인과 상태 API를 유지하세요. 새 이미지 생성이나 외부 API 연결은 필요 없습니다.
2. 메인 돼지는 제목 ‘우리 둘 가계부’ 옆이 아닌 ‘이번 달 함께 모은 돈’ 카드 오른쪽에 넣습니다. PNG 상자 96px부터 시작하고 모바일에서 80~96px 안에서 조절하세요. 금액과 수입/지출 영역을 가리지 않게 여백을 유지하세요. 원본을 늘이거나 새 캐릭터로 그리지 마세요.
3. 메인 상태는 wealthy / normal / hungry입니다. 실제 앱의 목표/예산 정책에서 명시적으로 전달합니다. 저장 금액만 보고 상태를 임의로 판정하지 마세요. 기존 정책이 없으면 정책 연결 지점을 남기고 normal로 시작하세요.
4. 바에는 얼굴 전용 happy / concerned / crying 이미지를 사용합니다. 귀여운 둥근 얼굴과 짧은 귀를 유지하세요. 아이콘 상자 24~28px, 바 높이 8px. 바 자체는 줄이지 말고 채워진 끝에 얼굴을 배치하세요. 0/100%에서도 잘리지 않아야 합니다.
5. 이 바는 예산 사용률입니다. 60% 미만 웃음, 60~90% 미만 걱정, 90% 이상 울음은 변경 가능한 예시 기준입니다. 기존 서비스 정책이 있으면 우선 사용하세요. 날짜를 고려하는 정책이면 PigBudgetBar의 state를 직접 지정할 수 있습니다. 현재 77% 예시는 concerned입니다.
6. 사용률이 100%를 넘으면 숫자는 실제 비율, 바 위치는 100%로 유지하세요. 예산이 0이거나 값이 누락되면 상태 미정으로 처리하세요. 숫자 계산은 기존 데이터를 사용하며 예시 금액으로 대체하지 마세요.
7. 기존 화면 색/레이아웃/최근 내역/내비게이션은 유지하세요. 자산의 기본 경로 `/pig-assets`는 프로젝트 배포 경로에 맞게 조정하세요. 접근성 텍스트와 reduced-motion 지원도 유지하세요.
8. 상태 3종, 모바일 크기, 0/60/77/90/100/120%, 예산 0원, 데이터 로딩 중을 확인하고 프로젝트의 관련 검사만 실행하세요.

사용자 취향: 부유한 돼지와 같은 부드러운 분홍 입체 그림체. 얼굴과 몸통이 이어진 둥근 돼지, 짧은 팔다리. 길쭉한 얼굴/사람 같은 몸은 싫어함. 배고픈 상태는 작은 기운 천과 빈 그릇 정도로 표현하고 심한 때/누더기 느낌을 추가하지 말 것. 메인 그림은 작게, 바는 더 작은 얼굴만 사용.
