# 웹앱 작업 전 점검 — 2026-10-02

## 점검 범위와 판단

Expo 클라이언트의 홈·내역·통계·설정, 입력/예산/월 선택 시트, 프로필·초대·알림 관련 코드와 공통 컴포넌트를 검토했다. 로컬 웹 미리보기에서 기존 테스트 계정으로 로그인해 홈·내역·통계·설정·내역 추가·지출 입력을 확인했다. 거래 생성·수정·삭제는 실행하지 않았다.

웹의 1280px, 360px, 320px 화면을 확인했다. 모바일 브라우저 크기로 확인한 결과는 Expo Go 실기기 검증을 대신하지 않는다. 네이티브 FPS, 다크 모드 전체 화면, 큰 시스템 글꼴, 실제 소프트 키보드, 오류/오프라인 상황의 모든 조합은 이번 시각 점검에 포함되지 않았다.

기본 기록 흐름은 동작하지만, 지금 상태를 그대로 공개 웹앱으로 배포하는 것은 권하지 않는다. 웹 로그인과 대량 내역 표시, 데스크톱 입력/레이아웃 작업을 먼저 계획해야 한다.

## 웹앱 출시 전에 남은 작업

### P1 — 웹 로그인은 현재 막혀 있음

`src/auth/kakao.ts`는 웹에서 카카오 로그인을 비활성화한다. 로그인 화면에서도 버튼이 비활성인 것을 확인했다. 개발/테스트 계정 패널은 운영용 로그인 대안이 아니다. 웹 OAuth 리다이렉트와 서버 인증 연결, 로그아웃/세션 만료 흐름을 구현하고 검증해야 한다. 웹 토큰 저장도 현재 코드에서 개발용 브라우저 저장소로 명시되어 있으므로 운영 웹 세션 설계 때 함께 검토한다.

### P1 — 내역 목록은 데이터가 많아지면 렌더 비용이 커짐

`app/(tabs)/history.tsx`는 ScrollView 내부에서 모든 날짜 그룹과 거래를 map으로 렌더한다. 월간 내역뿐 아니라 직접 지정한 긴 기간도 같은 방식이다. 보이지 않는 행까지 생성하므로 SectionList/FlatList 기반 가상화가 우선이다. 실제 기록 수에 따른 병목 시간은 측정하지 않았으며, 데이터가 적은 현재 화면의 체감만으로 성능을 보장할 수 없다.

통계는 월 페이지마다 겹치는 6개월 거래 원문을 받아 합산한다. 장기적으로 서버 집계 API 또는 월별 집계 캐시를 사용하면 전송량과 날짜 변환/집계 연산을 줄일 수 있다. 숫자 카운트업은 아직 JS/React 상태 갱신 방식이 남아 있다.

### P2 — 미구현 기능이 주요 화면에서 차지하는 비중

추가 메뉴 6개 중 지출/수입 2개만 사용 가능하다. 저금·대출·이체·목표는 준비 중이다. 설정에도 카테고리 관리·목표·내보내기·도움말이 준비 중이다. 비활성 표시 자체는 있으나, 첫 사용 경험에서 막힌 기능의 비중이 높다. 출시 범위가 정해지면 사용 가능한 기능 중심으로 메뉴를 정리하는 것이 좋다. 이번에는 기능을 임의로 삭제하지 않았다.

### P2 — 데스크톱 화면과 키보드 입력

1280px에서 모바일 카드가 화면 전체 너비로 늘어나고 하단 탭도 넓게 벌어진다. 웹 전용 최대 콘텐츠 폭, 2열 요약/통계, 내역 중심 레이아웃을 정해야 한다. 커스텀 금액 키패드는 물리 키보드 숫자 입력 흐름이 없어 웹에서는 마우스 클릭이 많아진다. 날짜 선택도 휠 이외의 직접 입력을 검토할 필요가 있다.

### P2 — 금액 의미와 비교 문구

홈의 `남은 돈`은 수입-지출이다. 계좌 잔액이나 실제 저축액을 뜻하지 않으므로 `수입−지출` 등으로 설명을 보강할 여지가 있다. 현재 월 통계는 이번 달 누적과 지난달 전체를 비교하므로 월초에 `지난달보다 덜 썼어요`가 오해를 줄 수 있다. 전체 월 대비임을 표시하거나 같은 일자까지 비교하는 정책을 선택해야 한다.

### P2 — 오류/동시 편집/시간대 추가 검증

4xx 서버 오류 문자열은 여전히 그대로 표시되며 서버에는 기술적인 문구가 남아 있다. 사용자용 메시지/오류 코드 분리가 필요하다. 예산의 기본값 변경과 월별 예외 해제는 서로 다른 요청이므로 이번 재조회 처리만으로 원자성이 생기지는 않는다. 함께 쓰는 사람의 동시 변경도 별도 시나리오로 검증해야 한다. 집계는 KST인데 거래 입력의 Date/시간 표시는 기기 로컬 시간대를 쓰는 부분이 있어 해외 시간대에서 날짜 경계를 확인해야 한다.

- 테스트 중 API URL 미설정 경고는 기존 API 단위 테스트에서 출력됨. 로컬 미리보기는 환경설정으로 접속함.
